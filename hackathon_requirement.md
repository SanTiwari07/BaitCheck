## 6. Embarko Technical Hosting Constraints (`embarko.ai/docs/*`)

| Constraint | Hard Rule | Engineering Impact on `BaitCheck` |
|---|---|---|
| **Single Web Process & Port** | Must listen on `0.0.0.0` and `process.env.PORT` (`node server.js`). Root `package.json` at top level. | Express/Node HTTP server serving static `/public` + REST API routes. |
| **Memory Cap** | **256 MB RAM hard cap** (cannot be raised). | Keep Node + `better-sqlite3` under **60 MB RAM**. Zero ML/OCR binaries on server. |
| **No Dockerfile** | Dockerfiles rejected at deploy time. | Standard Node.js repo without Dockerfile; omit `node_modules` when tar/uploading. |
| **No WebSockets** | `ws` / `Socket.IO` unsupported. | Use standard HTTP `fetch` + lightweight polling (`GET /api/challenge/:id`) for parent report updates. |
| **Persistent Database** | Disk outside `DATA_DIR` wipes on redeploy. Use SQLite inside `process.env.DATA_DIR`. Preserve `_litestream_seq` & `_litestream_lock` tables. | Use `CREATE TABLE IF NOT EXISTS` in `DATA_DIR/baitcheck.db`; never run destructive ORM schema-diff syncs. |
| **Cron Schedules** | In-process cron fails on sleep. Declare up to 5 GET routes in root `embarko.json` secured by `Authorization: Bearer $CRON_SECRET`. | Declare `/tasks/daily-stats` in `embarko.json` to refresh anonymized trap benchmarks. |
| **File Storage** | Upload generated PNGs via `PUT ${STORAGE_URL}/apps/${APP_NAME}/files/{name}` with `Bearer ${STORAGE_TOKEN}`. | Optional Canvas Verdict Ticket PNG upload for permanent shareable links. |
| **CSP Override** | Embarko replaces CSP headers (`self`, `https:`, `data:`, `blob:`, `wasm`; third-party embeds blocked). | Keep JS/CSS/WebAudio self-contained inside `/public` (Google Fonts `Archivo` over HTTPS or local fallback). |
| **Abuse & Uptime Policy** | Apps that crash, go offline, or look like phishing/malware risk removal and disqualification. | Mandatory anti-phishing guardrails: fictional entities, permanent `SIMULATION` ribbon, zero OTP/PIN/password inputs, zero downloads. |
